Images of the Russian Empire

Colorizing the Prokudin Gorskii photo collection through image alignment

Sergei Prokudin Gorskii recorded many scenes of the Russian Empire using three separate monochrome exposures captured through blue, green, and red filters. The three channel images are stored vertically on the same glass plate. If these channels are correctly aligned and stacked together, they can be reconstructed into a color photograph.

The main challenge is therefore geometric alignment. I use the blue channel as the reference and estimate the translation required to align the green and red channels with it. Small JPEG images can be aligned through an exhaustive translation search. Large TIF images require a coarse to fine image pyramid so that large displacements can be recovered efficiently. For difficult cases such as Emir, I further use edge structure to make the alignment less sensitive to large brightness differences between color channels.

Part 1  Single Scale Channel Alignment

3 JPEG images

For the smaller JPEG images, the possible displacement between color channels is limited. I therefore search directly over a small two dimensional translation window and choose the displacement that produces the best agreement with the blue reference channel.

Translation Model Alignment Geometry

The three exposures represent the same static scene, so the main geometric difference between channels can be approximated by a two dimensional translation. Let \(\Delta=(\Delta x,\Delta y)\) denote the displacement applied to a channel.

\[ I_{\Delta}(x,y) = I \left( x-\Delta x,\, y-\Delta y \right) \]

The blue image is kept fixed. I independently estimate one displacement for the green channel and another for the red channel.

\[ \boxed{ \Delta_G^* = \operatorname*{arg\,best}_{\Delta} S \left( B,\, G_{\Delta} \right) } \]
\[ \boxed{ \Delta_R^* = \operatorname*{arg\,best}_{\Delta} S \left( B,\, R_{\Delta} \right) } \]

All reported shifts below are written as \((\Delta x,\Delta y)\).

Alignment Metrics SSD and NCC

For every candidate displacement, the shifted channel must be compared with the blue reference. I considered both Sum of Squared Differences and Normalized Cross Correlation.

Sum of Squared Differences

SSD directly measures pixelwise intensity disagreement. Smaller values indicate better alignment.

Normalized Cross Correlation

NCC measures the structural similarity between normalized image intensities. Larger values indicate better alignment.

\[ \boxed{ E_{\mathrm{SSD}}(\Delta) = \sum_{x,y} \left[ B(x,y) - I_{\Delta}(x,y) \right]^2 } \]

SSD chooses the displacement with the smallest error.

\[ \boxed{ \Delta^* = \arg\min_{\Delta} E_{\mathrm{SSD}}(\Delta) } \]

NCC first removes the local mean and normalizes the magnitude of the compared image vectors.

\[ \boxed{ \operatorname{NCC}(A,B) = \frac{ \sum (A-\bar A) (B-\bar B) }{ \sqrt{ \sum (A-\bar A)^2 \sum (B-\bar B)^2 } } } \]

This normalization makes the score less sensitive to global brightness and contrast differences between channels. In my experiments, NCC produced more reliable alignment than SSD.

Exhaustive Translation Search Implementation

I first split the vertically concatenated plate into blue, green, and red grayscale images. Border regions are cropped before alignment because the plate boundaries contain strong structures that do not correspond to the photographed scene and can dominate the matching score.

I empirically found that cropping approximately 13 percent from the image boundaries produced stable results.

For each of the green and red channels, I evaluate candidate translations within \([-15,15]\) pixels along both axes.

\[ \boxed{ \Delta x,\Delta y \in [-15,15] } \]

The displacement with the highest NCC score is applied to the channel. The aligned blue, green, and red channels are then stacked into the final RGB image.

\[ \boxed{ I_{\mathrm{RGB}} = \operatorname{stack} \left( R_{\Delta_R^*}, G_{\Delta_G^*}, B \right) } \]

Part 2  Coarse to Fine Pyramid Alignment

11 TIF images

The high resolution TIF images contain much larger displacements. Searching a very large translation window directly at full resolution would be unnecessarily expensive. I therefore estimate the displacement from coarse to fine using a Gaussian image pyramid.

Gaussian Image Pyramid Multiscale Search

The pyramid repeatedly smooths and downsamples an image. Large translations at the original resolution become much smaller at coarse scales. This allows the alignment to begin with a small local search.

\[ \boxed{ I^{\ell+1} = \operatorname{Downsample} \left( G * I^{\ell} \right) } \]

I construct six pyramid levels for each color channel. Each level reduces the image width and height by approximately a factor of two.

Before downsampling, I apply a separable Gaussian filter using

\[ \boxed{ g = \frac{1}{16} \begin{bmatrix} 1 & 4 & 6 & 4 & 1 \end{bmatrix} } \]

The smoothing operation reduces aliasing before the resolution is decreased.

Coarse to Fine Search Displacement Refinement

Alignment begins at the coarsest level. I search only a small displacement window and estimate an initial translation. When moving to the next finer level, the image dimensions double, so the previous displacement must also be doubled.

\[ \boxed{ \Delta_{\ell-1}^{\mathrm{init}} = 2\Delta_{\ell} } \]

I then search for a small residual displacement \(\delta_{\ell-1}\) around this prediction.

\[ \boxed{ \Delta_{\ell-1} = 2\Delta_{\ell} + \delta_{\ell-1} } \]

At each level, the residual search is restricted to \([-5,5]\) pixels along both axes.

\[ \boxed{ \delta x,\delta y \in [-5,5] } \]

This process continues until the original resolution is reached. Large motion is resolved cheaply at coarse scales, while the finer levels only refine the estimate.

With six pyramid levels and a small local search window, the full TIF collection can be processed in under roughly ten seconds in my implementation.

Edge Based Robustness Emir

The pyramid method aligns almost all images successfully using raw intensity values. Emir is a more difficult case because the red and blue filtered exposures have substantially different brightness patterns.

Even when two channels are geometrically aligned, corresponding pixels may therefore have very different intensities. An intensity based similarity score can become unreliable.

To improve robustness, I compare structural edge information rather than raw brightness. I use Canny edge detection after border cropping and perform the same alignment search on the resulting edge maps.

\[ \boxed{ I \longrightarrow \text{Edge Map} \longrightarrow \text{Alignment Score} } \]

Edges emphasize scene boundaries and geometric structure while reducing sensitivity to large photometric differences between color channels. This resolves the difficult red channel alignment for Emir.
