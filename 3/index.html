1.1 Convolution from Scratch

  1. Convolution is one of the basic operations used throughout image processing. It transforms an image by moving a small filter kernel across the image and computing a weighted combination of nearby pixel values. Different kernels therefore allow the same computational operation to perform very different types of image processing.

    Let \(I\) denote an image and \(K\) denote a filter kernel. The filtered image can be written as

    \[ \boxed{ (I*K)[m,n] = \sum_{i} \sum_{j} K[i,j] I[m-i,n-j] } \]

    Each output pixel is produced from a local neighborhood of the original image. The kernel determines how strongly each neighboring pixel contributes to the result.

    \[ \boxed{ \text{Input Image} \longrightarrow \text{Local Neighborhood} \longrightarrow \text{Weighted Sum} \longrightarrow \text{Output Pixel} } \]

    As a first example, I use a \(9\times9\) box filter. Every entry in the kernel has the same weight, so each output pixel becomes the average of a local \(9\times9\) neighborhood.

    \[ \boxed{ K_{\mathrm{box}} = \frac{1}{81} \mathbf 1_{9\times9} } \]

    Averaging nearby pixels suppresses rapid local intensity changes. The resulting image therefore appears smoother and contains less fine detail.

    I implemented convolution from scratch in two different ways. The first implementation uses four explicit loops. The outer two loops visit every output pixel, while the inner two loops traverse the filter window and accumulate the weighted pixel values.

    \[ \boxed{ \text{Image Rows} \times \text{Image Columns} \times \text{Kernel Rows} \times \text{Kernel Columns} } \]

    The second implementation keeps the two outer loops over output pixels but replaces the two inner loops with NumPy array operations. For each output location, the corresponding image patch is multiplied with the kernel and summed using vectorized computation.

    \[ \boxed{ I_{\mathrm{patch}} \odot K \longrightarrow \operatorname{sum} \longrightarrow I_{\mathrm{out}}[m,n] } \]

    In both implementations, I use zero padding around the image boundary. Without padding, the kernel cannot be centered on pixels close to the image border and the output image would become smaller. Padding preserves the original spatial dimensions.

    \[ \boxed{ H\times W \longrightarrow \text{Zero Padding} \longrightarrow \text{Convolution} \longrightarrow H\times W } \]

    I apply both implementations to the same selfie using the \(9\times9\) box filter. The two implementations produce the same smoothing result.

    selfie_two_loops.png

    \[ \boxed{ \text{Four Loop Result} \approx \text{Two Loop Result} \approx \text{SciPy Result} } \]

  4. Although the three implementations produce the same filtered image, their computational costs are very different. The four loop version performs nearly all operations through explicit Python iteration and is therefore the slowest. The two loop version uses NumPy to perform the kernel computation more efficiently. The SciPy implementation is substantially more optimized and achieves the shortest runtime in this experiment.

    \[ \boxed{ T_{\mathrm{four\ loops}} > T_{\mathrm{two\ loops}} > T_{\mathrm{SciPy}} } \]
    runtime.png

    This comparison illustrates an important distinction between the mathematical definition of an image operation and its computational implementation. All three methods implement the same filtering idea, while vectorization and optimized numerical routines make the computation much more efficient.

  5. The box filter demonstrates that changing the kernel changes the behavior of convolution. I next replace the averaging kernel with finite difference filters.

    \[ \boxed{ D_x = \begin{bmatrix} 1 & 0 & -1 \end{bmatrix} } \]
    \[ \boxed{ D_y = \begin{bmatrix} 1\\ 0\\ -1 \end{bmatrix} } \]

    Instead of averaging neighboring intensities, these filters measure local intensity change. Convolution with \(D_x\) measures horizontal intensity variation, while convolution with \(D_y\) measures vertical intensity variation.

    \[ \boxed{ I_x = I*D_x, \qquad I_y = I*D_y } \]

    Regions with little intensity variation produce values close to zero. Strong transitions produce responses with larger magnitude. This makes finite difference filters useful for detecting image structure such as edges.

    selfie_Dx.png
    selfie_Dy.png

  6. This section establishes convolution as a general framework for image filtering. The same operation can smooth an image or measure local image derivatives simply by changing the kernel.

    \[ \boxed{ \begin{aligned} \text{Box Kernel} &\longrightarrow \text{Local Averaging} \longrightarrow \text{Smoothing} \\ D_x,\ D_y &\longrightarrow \text{Local Differences} \longrightarrow \text{Image Derivatives} \end{aligned} } \]

    The finite difference responses provide the horizontal and vertical components of the image gradient. In the next section, I combine these components to measure edge strength and construct a binary edge map.

1.2 Finite Differences and Edge Detection

  1. After using finite difference filters in the previous section, I apply them to the Cameraman image to construct an edge map. The central idea is that an edge corresponds to a rapid change in image intensity. Image derivatives provide a direct way to measure these changes.

    The original grayscale image is shown below.

    cameraman.png

    I first convolve the image with the horizontal and vertical finite difference operators introduced in Part 1.1.

    \[ D_x = \begin{bmatrix} 1 & 0 & -1 \end{bmatrix}, \qquad D_y = \begin{bmatrix} 1\\ 0\\ -1 \end{bmatrix} \]

    These filters approximate the partial derivatives of the image along the horizontal and vertical directions.

    \[ \boxed{ I_x = I*D_x, \qquad I_y = I*D_y } \]

    The horizontal derivative \(I_x\) responds strongly where intensity changes rapidly as we move across image columns. The vertical derivative \(I_y\) responds strongly where intensity changes rapidly as we move across image rows.

    Together, these two derivative images describe the local image gradient.

    \[ \boxed{ \nabla I = \begin{bmatrix} I_x\\ I_y \end{bmatrix} } \]
    cameraman_Dx.png
    cameraman_Dy.png

  2. The two derivative components can be combined into a single measure of how strongly the image changes at every pixel. This quantity is the gradient magnitude.

    \[ \boxed{ \left\| \nabla I \right\| = \sqrt{ I_x^2 + I_y^2 } } \]

    A small gradient magnitude indicates that the local image intensity changes slowly. A large gradient magnitude indicates a strong local transition and is therefore evidence of an edge.

    \[ \boxed{ \begin{aligned} \left\| \nabla I \right\| \text{ small} &\longrightarrow \text{Smooth Region} \\ \left\| \nabla I \right\| \text{ large} &\longrightarrow \text{Strong Edge} \end{aligned} } \]

    The gradient also has an orientation given by

    \[ \theta = \operatorname{atan2} \left( I_y, I_x \right) \]

    This direction indicates the direction of the fastest increase in image intensity. For this part of the project, I only need the gradient magnitude because the goal is to measure edge strength rather than edge orientation.

    cameraman_grad_mag.png

  3. The gradient magnitude is still a continuous valued image. To obtain a binary edge map, I apply a threshold that separates strong gradient responses from weak ones.

    \[ \boxed{ E(x,y) = \begin{cases} 255, & \left\| \nabla I(x,y) \right\| \geq \tau \\ 0, & \left\| \nabla I(x,y) \right\| < \tau \end{cases} } \]

    The choice of threshold controls the tradeoff between retaining weak edges and suppressing small responses. A very low threshold keeps many weak gradients, including responses caused by noise and texture. A very high threshold removes noise more aggressively but may also discard meaningful edges.

    I found that a threshold of \(35\) provides a reasonable balance for this image. Strong object boundaries are preserved while many weaker responses are removed.

    \[ \boxed{ \tau = 35 } \]
    cameraman_binarized.png

  4. The complete edge detection procedure can therefore be summarized as

    \[ \boxed{ \text{Image} \longrightarrow D_x,\ D_y \longrightarrow I_x,\ I_y \longrightarrow \left\| \nabla I \right\| \longrightarrow \text{Threshold} \longrightarrow \text{Binary Edge Map} } \]

    One limitation becomes visible in this process. Finite difference filters respond to rapid intensity changes, but image noise also consists largely of rapid local variations. Derivative filters can therefore amplify noise together with real edges.

    The next section addresses this problem by smoothing the image with a Gaussian before differentiation. It also shows that smoothing followed by differentiation can be combined into a single Derivative of Gaussian filter through the algebraic properties of convolution.

1.3 Derivative of Gaussian

  1. In the previous section, finite difference filters were used to detect image edges from local intensity changes. However, these derivative filters also respond strongly to small high frequency variations caused by image noise. This can introduce many weak and unstable responses into the edge map.

    To make the derivative estimate more robust, I first smooth the image using a Gaussian filter. Gaussian filtering averages nearby pixels with smoothly decaying weights, which suppresses high frequency noise while preserving larger image structures.

    \[ \boxed{ I_{\mathrm{smooth}} = I * G } \]

    After smoothing, I apply the finite difference filters to the Gaussian filtered image.

    \[ \boxed{ I_x = (I*G)*D_x } \]
    \[ \boxed{ I_y = (I*G)*D_y } \]

    The horizontal and vertical derivative responses can then be combined using the same gradient magnitude computation as in the previous section.

    \[ \boxed{ \left\| \nabla I \right\| = \sqrt{ I_x^2 + I_y^2 } } \]

    Because the image is smoothed before differentiation, small noisy variations are reduced before the derivative filters are applied. The resulting edge map is therefore cleaner and emphasizes larger, more stable image boundaries.

    Gaussian smoothing followed by differentiation

  2. The same operation can also be performed in a single filtering step. Convolution is associative, which means that the order in which consecutive filters are grouped does not change the final result.

    \[ \boxed{ (I*G)*D_x = I*(G*D_x) } \]
    \[ \boxed{ (I*G)*D_y = I*(G*D_y) } \]

    Instead of first smoothing the image and then differentiating it, I can therefore differentiate the Gaussian filter itself.

    \[ \boxed{ G_x = G*D_x, \qquad G_y = G*D_y } \]

    These filters are Derivative of Gaussian filters. They combine smoothing and differentiation into a single kernel.

    \[ \boxed{ I_x = I*G_x, \qquad I_y = I*G_y } \]

    The result is mathematically equivalent to first applying the Gaussian filter and then applying the finite difference operator. The difference is that the two filtering operations have been combined before being applied to the image.

    \[ \boxed{ \text{Smooth Then Differentiate} = \text{Differentiate the Gaussian Then Filter} } \]
    Derivative of Gaussian result

  3. The two approaches produce the same result because they represent the same sequence of linear filtering operations. The difference lies only in when the filters are combined.

    \[ \boxed{ \begin{aligned} \text{Two Step Method} &\qquad I \longrightarrow I*G \longrightarrow (I*G)*D \\ \text{One Step Method} &\qquad G*D \longrightarrow I*(G*D) \end{aligned} } \]

    This example illustrates an important property of convolution. Multiple linear filters can often be combined into a single filter before being applied to the image. This allows us to understand image processing operations not only as sequences of steps, but also as combinations of kernels.

    It also introduces a frequency based interpretation that becomes important in the next part of the project. Gaussian smoothing suppresses high frequency components, while image derivatives emphasize rapid intensity changes. Combining the two produces a derivative operator that is less sensitive to high frequency noise.

    \[ \boxed{ \text{Gaussian Smoothing} \longrightarrow \text{Noise Suppression} \longrightarrow \text{Differentiation} \longrightarrow \text{Cleaner Edge Response} } \]

2.1 Image Sharpening with the Unsharp Mask

  1. The previous sections used Gaussian filtering to suppress rapid intensity variation and produce a smoother image. Image sharpening uses the same frequency decomposition in the opposite direction. Instead of removing fine scale variation, we first isolate it and then amplify it.

    An image can be viewed as a combination of slowly varying structure and rapidly varying detail. Gaussian filtering acts as a low pass filter, so convolving an image \(I\) with a Gaussian kernel \(G\) produces its low frequency component.

    \[ \boxed{ I_{\mathrm{low}} = I*G } \]

    The information removed by this smoothing operation can be recovered by subtracting the blurred image from the original image. This residual contains the higher frequency structures that the Gaussian filter attenuated.

    \[ \boxed{ I_{\mathrm{high}} = I-I_{\mathrm{low}} = I-I*G } \]

    Strong edges, fine texture, and other rapid intensity changes are therefore emphasized in \(I_{\mathrm{high}}\). Sharpening is performed by adding a scaled version of this component back to the original image.

    \[ \boxed{ I_{\mathrm{sharp}} = I + \alpha I_{\mathrm{high}} } \]

    Substituting the high frequency component gives

    \[ \boxed{ I_{\mathrm{sharp}} = I + \alpha \left( I-I*G \right) } \]

    The parameter \(\alpha\) controls the amount of sharpening. When \(\alpha\) is small, the additional high frequency contribution is weak. Increasing \(\alpha\) makes edges and fine structures more pronounced. Very large values can also amplify noise and produce an unnaturally strong appearance.

    \[ \boxed{ \alpha \uparrow \qquad \Longrightarrow \qquad \text{Stronger High Frequency Emphasis} } \]

    The first experiment applies this process to the Taj Mahal image. The sequence shows the original image, its Gaussian blurred version, the extracted high frequency component, and two sharpened results obtained with different values of \(\alpha\).

  2. The previous formulation appears to require several operations. We first blur the image, subtract the blurred image from the original, and then add the scaled residual back. Because convolution is linear, these operations can be combined into one convolution kernel.

    Let \(\delta\) denote the unit impulse kernel. Convolution with \(\delta\) leaves an image unchanged.

    \[ \boxed{ I*\delta = I } \]

    Starting from the sharpening equation, we can rearrange the terms as

    \[ \begin{aligned} I_{\mathrm{sharp}} &= I + \alpha \left( I-I*G \right) \\ &= (1+\alpha)I - \alpha I*G \end{aligned} \]

    Replacing the unchanged image with convolution by the unit impulse gives

    \[ \begin{aligned} I_{\mathrm{sharp}} &= (1+\alpha) I*\delta - \alpha I*G \\ &= I* \left[ (1+\alpha)\delta - \alpha G \right] \end{aligned} \]

    The complete sharpening operation can therefore be represented by a single filter.

    \[ \boxed{ K_{\mathrm{unsharp}} = (1+\alpha)\delta - \alpha G } \]

    Convolving the original image with this kernel directly produces the same unsharp masking result. The two formulations therefore describe the same operation from two different perspectives.

    \[ \boxed{ \text{Extract Details Then Add Them Back} = \text{Convolve with One Unsharp Mask Kernel} } \]

  3. I also test what happens when information has already been removed from an image. I begin with a sharp image, deliberately blur it, and then apply sharpening to the blurred result.

    This experiment highlights an important limitation of unsharp masking. Sharpening does not recreate high frequency information that was destroyed during blurring. It only amplifies the frequency content that still remains in the blurred image.

    \[ \boxed{ \text{Blur} \longrightarrow \text{Loss of High Frequency Information} } \]
    \[ \boxed{ \text{Sharpening} \longrightarrow \text{Amplification of Remaining Detail} } \]

    The resharpened image can therefore appear crisper than the blurred version, but it is not identical to the original sharp image. Fine structures that were strongly suppressed by the Gaussian filter cannot be recovered simply by increasing their contrast afterward.

    Blur followed by resharpening

  4. Image sharpening can therefore be understood as a controlled manipulation of spatial frequencies. Gaussian filtering extracts the low frequency structure, subtraction isolates the higher frequency detail, and unsharp masking amplifies that detail before combining it with the original image.

    \[ \boxed{ \text{Image} \longrightarrow \text{Low Frequency} + \text{High Frequency} \longrightarrow \text{Amplify High Frequency} \longrightarrow \text{Sharpened Image} } \]

    The next section uses the same frequency decomposition in a different way. Instead of combining the low and high frequency components from one image, hybrid images combine low frequencies from one image with high frequencies from another.

2.2 Hybrid Images

  1. The previous section used low and high frequency components from the same image to perform sharpening. Hybrid images use the same frequency decomposition in a different way. The low frequency structure of one image is combined with the high frequency detail of another image.

    \[ \boxed{ I_{\mathrm{hybrid}} = w_{\mathrm{low}} I_{\mathrm{low}} + w_{\mathrm{high}} I_{\mathrm{high}} } \]

    The effect works because visual perception depends on spatial frequency and viewing distance. High frequency structures correspond to rapid local intensity changes and fine details. They are especially noticeable when the image is viewed nearby. Low frequency structures correspond to slowly varying coarse shapes and remain visible more strongly when the image is viewed from a greater distance.

    \[ \boxed{ \begin{aligned} \text{Near View} &\longrightarrow \text{High Frequency Detail Becomes More Salient} \\ \text{Far View} &\longrightarrow \text{Low Frequency Structure Becomes More Salient} \end{aligned} } \]

    To obtain the low frequency component, I convolve an image with a Gaussian filter.

    \[ \boxed{ I_{\mathrm{low}} = I_A*G_{\sigma_{\mathrm{low}}} } \]

    The Gaussian suppresses rapid spatial variation and preserves the coarse structure of the image. The parameter \(\sigma\) determines the scale of this smoothing. Increasing \(\sigma\) removes a wider range of high frequency detail.

    To obtain the high frequency component of the second image, I subtract its Gaussian filtered version from the original image.

    \[ \boxed{ I_{\mathrm{high}} = I_B - I_B*G_{\sigma_{\mathrm{high}}} } \]

    Using the unit impulse kernel \(\delta\), the same operation can be written as a single convolution.

    \[ \boxed{ I_{\mathrm{high}} = I_B* \left( \delta - G_{\sigma_{\mathrm{high}}} \right) } \]

    The kernel \(\delta-G\) therefore behaves as a high pass filter. Slowly varying image structure is removed while faster local changes such as edges and texture remain.

    The full construction can be summarized as

    \[ \boxed{ \begin{aligned} I_A &\longrightarrow \text{Gaussian Low Pass} \longrightarrow I_{\mathrm{low}} \\ I_B &\longrightarrow \text{High Pass} \longrightarrow I_{\mathrm{high}} \\ I_{\mathrm{low}} + I_{\mathrm{high}} &\longrightarrow I_{\mathrm{hybrid}} \end{aligned} } \]

    I first apply this procedure to the provided Derek and Nutmeg images. I use \(\sigma_{\mathrm{low}}=4.0\) for the low pass component and \(\sigma_{\mathrm{high}}=7.0\) for the high pass component. Both components are combined with equal weights.

    \[ \boxed{ w_{\mathrm{low}} = 0.5, \qquad w_{\mathrm{high}} = 0.5 } \]

    The final image contains information from both sources at different spatial scales. When viewed nearby, the high frequency component contributes much of the visible fine structure. As the viewing distance increases, these fine structures become less perceptually dominant and the low frequency component increasingly determines the overall appearance.

  2. The same filtering process can also be understood in the frequency domain. The Fourier transform represents an image according to how much energy it contains at different spatial frequencies.

    \[ \boxed{ I(x,y) \longleftrightarrow \mathcal F \left\{ I(x,y) \right\} } \]

    In the centered Fourier visualizations below, frequencies near the center represent slower spatial variation, while locations farther from the center represent faster spatial variation.

    Gaussian low pass filtering concentrates the retained information near the low frequency region. High pass filtering suppresses this low frequency content and keeps more of the fine scale structure. The hybrid spectrum contains contributions from both frequency ranges.

    This frequency interpretation is consistent with the convolution theorem. Convolution with a filter in the spatial domain corresponds to multiplication by that filter response in the frequency domain.

    \[ \boxed{ \mathcal F \left\{ I*K \right\} = \mathcal F \left\{ I \right\} \mathcal F \left\{ K \right\} } \]

    The following images visualize the frequency content of the original images, the filtered components, and the final hybrid result.

    Derek spectrum

    These visualizations show that the hybrid image does not simply average two photographs. It deliberately preserves different spatial frequency ranges from the two source images.

    \[ \boxed{ \text{Hybrid Image} = \text{Coarse Structure from One Image} + \text{Fine Structure from Another} } \]

    \[ \boxed{ I_{\mathrm{hybrid}} = 0.45 I_{\mathrm{low}} + 0.55 I_{\mathrm{high}} } \]

    The values of the Gaussian scales and mixing weights determine how strongly each source contributes to the final percept. The Gaussian scales control which spatial structures are assigned to the low and high frequency components, while the mixing weights control their relative visual strength.

  4. Hybrid images demonstrate that frequency decomposition is not only a mathematical representation of an image. Different frequency bands can carry different perceptual information, and they can be manipulated independently to construct an image whose interpretation changes with viewing scale.

    \[ \boxed{ \text{Image A} \longrightarrow \text{Low Frequencies} } \]
    \[ \boxed{ \text{Image B} \longrightarrow \text{High Frequencies} } \]
    \[ \boxed{ \text{Low Frequencies} + \text{High Frequencies} \longrightarrow \text{Scale Dependent Perception} } \]

    The next section extends the same frequency decomposition idea from only two frequency ranges to multiple scales. Gaussian and Laplacian stacks allow an image to be separated into a sequence of frequency bands, which later makes multiresolution blending possible.

2.3 Gaussian and Laplacian Stacks

  1. The previous section separated an image into only two broad frequency ranges. A low pass filter produced coarse image structure, while subtraction from the original image produced high frequency detail. For multiresolution blending, it is useful to extend this idea and represent an image using several spatial frequency ranges instead of only two.

    \[ \boxed{ \text{Image} \longrightarrow \text{Multiple Spatial Scales} \longrightarrow \text{Multiple Frequency Bands} } \]

    I begin by constructing a Gaussian stack. Every level is obtained by smoothing the original image using a Gaussian filter with an increasingly large scale.

    \[ \boxed{ G_i = I*G_{\sigma_i} } \]

    The first level contains nearly all of the original image structure. As the smoothing scale increases, fine details disappear and each later level contains progressively lower frequency information.

    \[ \boxed{ G_0, G_1, G_2, \ldots, G_n } \]

    This project uses a stack rather than a traditional Gaussian pyramid. A traditional pyramid repeatedly smooths and downsamples the image. In a stack, every level remains at the same spatial resolution and only the amount of Gaussian smoothing changes.

    \[ \boxed{ \begin{aligned} \text{Pyramid} &\qquad \text{Smoothing} + \text{Downsampling} \\ \text{Stack} &\qquad \text{Smoothing Only} \end{aligned} } \]

    The Gaussian stack contains cumulative low frequency information. To isolate individual frequency ranges, I subtract neighboring Gaussian levels and construct a Laplacian stack.

    \[ \boxed{ L_i = G_i-G_{i+1} } \]

    The final level stores the remaining lowest frequency component.

    \[ \boxed{ L_n = G_n } \]

    Each Laplacian level therefore contains image structure that is present at one Gaussian scale but removed at the next. Earlier levels contain finer spatial details, while later levels contain progressively coarser structures.

    \[ \boxed{ \begin{aligned} L_0 &\longrightarrow \text{Fine Detail} \\ L_1,L_2,\ldots &\longrightarrow \text{Intermediate Scales} \\ L_n &\longrightarrow \text{Coarse Structure} \end{aligned} } \]

    Another useful property of the Laplacian stack is that the original image can be reconstructed exactly by adding all of its levels. This follows directly from the telescoping differences between neighboring Gaussian levels.

    \[ \begin{aligned} \sum_{i=0}^{n}L_i &= (G_0-G_1) + (G_1-G_2) + \cdots + (G_{n-1}-G_n) + G_n \\ &= G_0 \end{aligned} \]
    \[ \boxed{ I = \sum_{i=0}^{n}L_i } \]

    I construct Laplacian stacks for both source images. The following row shows the seven levels of the first image. Moving from left to right reveals increasingly coarse spatial structure.

    The Laplacian stacks give us a representation in which image structures at different scales can be manipulated independently. This is exactly what is needed for multiresolution blending. Rather than blending an entire image using one transition width, the next section blends each frequency band using a transition scale that is appropriate for that level.

    \[ \boxed{ \text{Gaussian Stack} \longrightarrow \text{Laplacian Stack} \longrightarrow \text{Frequency Bands} \longrightarrow \text{Multiresolution Blending} } \]
2.4 Multiresolution Blending

  1. With the two source images represented by Laplacian stacks, the next step is to combine them into a seamless image. A simple approach would be to use a spatial mask and directly blend the two images.

    \[ \boxed{ I_{\mathrm{blend}} = M I_A + (1-M)I_B } \]

    Here, \(M\) determines how much each source contributes at every image location. A value near one selects the first image, while a value near zero selects the second image.

    The difficulty is choosing the spatial transition of this mask. If the transition is too sharp, the boundary between the two images can remain visible as a seam. If the transition is too broad, unrelated structures from both images can overlap and create ghosting.

    \[ \boxed{ \begin{aligned} \text{Sharp Transition} &\longrightarrow \text{Visible Seam} \\ \text{Wide Smooth Transition} &\longrightarrow \text{Possible Ghosting} \end{aligned} } \]

    The reason one transition width is insufficient is that an image contains structures at many spatial frequencies. Fine details and coarse appearance changes should not necessarily be blended over the same spatial scale.

    Multiresolution blending solves this problem by blending each Laplacian frequency band separately. I first construct a Gaussian stack from the blending mask using the same smoothing scales used for the image stacks.

    \[ \boxed{ G_M^0, G_M^1, G_M^2, \ldots, G_M^n } \]

    Earlier mask levels remain relatively sharp, while later levels are increasingly smooth. The mask therefore changes rapidly for fine image structure and more gradually for coarse image structure.

    \[ \boxed{ \begin{aligned} \text{Fine Frequency Bands} &\longrightarrow \text{Sharper Mask} \\ \text{Coarse Frequency Bands} &\longrightarrow \text{Smoother Mask} \end{aligned} } \]

    For every level \(i\), I combine the corresponding Laplacian bands of the two images using the Gaussian filtered mask at the same scale.

    \[ \boxed{ L_{\mathrm{blend}}^i = G_M^iL_A^i + \left( 1-G_M^i \right) L_B^i } \]

    The following images show the blended Laplacian levels from fine to coarse spatial scales.

    Because this project uses stacks rather than downsampled pyramids, reconstruction does not require repeated upsampling. The final image is obtained by adding all blended Laplacian levels.

    \[ \boxed{ I_{\mathrm{blend}} = \sum_{i=0}^{n} L_{\mathrm{blend}}^i } \]

    The complete procedure can therefore be summarized as

    \[ \boxed{ \begin{gathered} \text{Laplacian Stack of Image A} \\ + \\ \text{Laplacian Stack of Image B} \\ + \\ \text{Gaussian Stack of Mask} \\ \downarrow \\ \text{Blend Corresponding Frequency Bands} \\ \downarrow \\ \text{Sum All Blended Levels} \\ \downarrow \\ \text{Final Image} \end{gathered} } \]

  4. Multiresolution blending works because different spatial frequencies are allowed to transition between the two source images over different distances. Fine structures are blended more locally, while coarse structures change more gradually.

    \[ \boxed{ \text{Different Frequency Bands} + \text{Different Mask Scales} \longrightarrow \text{Smooth Multiscale Transition} } \]

    This completes the frequency based progression of Part Two. Sharpening amplified high frequency information within one image, hybrid images combined frequency ranges from two images, and multiresolution blending extended the same idea across many spatial scales.

    \[ \boxed{ \text{Sharpening} \longrightarrow \text{Two Band Frequency Manipulation} \longrightarrow \text{Hybrid Images} \longrightarrow \text{Multiscale Frequency Blending} } \]
