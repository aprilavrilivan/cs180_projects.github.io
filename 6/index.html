Forward Process 1.1

  1. The following demonstrates the forward diffusion process used in diffusion models.

    The key idea of the forward process is to gradually destroy the information in a clean image by injecting Gaussian noise. Starting from the original image \(x_0\), diffusion defines a Markov chain:

    \[ x_0 \rightarrow x_1 \rightarrow x_2 \rightarrow ... \rightarrow x_T \]

    At each timestep \(t\), a small amount of Gaussian noise is added:

    \[ q(x_t|x_{t-1}) = \mathcal{N} \left( \sqrt{1-\beta_t}x_{t-1}, \beta_t I \right) \]

    Equivalently, the transition can be written as:

    \[ x_t= \sqrt{1-\beta_t}x_{t-1} + \sqrt{\beta_t}\epsilon, \quad \epsilon\sim\mathcal{N}(0,I) \]

    Here, \(\beta_t\) controls the amount of noise added at timestep \(t\). A small \(\beta_t\) preserves more image structure, while a larger \(\beta_t\) gradually destroys the original information.

    However, applying this transition repeatedly is inefficient. During training, we need to randomly sample different noise levels, so DDPM derives a closed-form formulation that allows us to directly generate \(x_t\) from \(x_0\) without iterating through all previous steps:

    \[ x_t= \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon \]

    where:

    \[ \alpha_t=1-\beta_t, \qquad \bar{\alpha}_t=\prod_{i=1}^{t}\alpha_i \]

    This formulation allows us to directly sample an arbitrary noise level \(t\) from the original image, which is the key insight behind efficient diffusion model training.

    The square-root coefficients ensure that the signal and noise components remain properly normalized. If we write:

    \[ x_t=ax_0+b\epsilon \]

    the variance contribution of each component is determined by the square of its coefficient. Therefore, diffusion chooses:

    \[ a=\sqrt{\bar{\alpha}_t}, \qquad b=\sqrt{1-\bar{\alpha}_t} \]

    such that:

    \[ (\sqrt{\bar{\alpha}_t})^2+ (\sqrt{1-\bar{\alpha}_t})^2=1 \]

    This keeps the total variance stable while smoothly controlling the trade-off between image information and noise.

    In practice, the noise schedule determines how quickly the original information disappears. At early timesteps:

    \[ \bar{\alpha}_t\approx1 \Rightarrow x_t\approx x_0 \]

    while at later timesteps:

    \[ \bar{\alpha}_t\approx0 \Rightarrow x_t\approx\epsilon \]

    Modern diffusion models often use cosine noise schedules instead of simple linear schedules, providing a smoother information decay across timesteps and allocating denoising difficulty more evenly throughout the trajectory.

Learned Denoiser Denoising 1.3

  1. Since classical Gaussian filtering cannot reliably recover the image structure at high noise levels, a better approach is to use a learned denoiser. Here, I use the stage_1.unet of the DeepFloyd model for one-step denoising.

    The model takes as input a noisy image \(x_t\), the prompt "a high quality photo", and the timestep \(t\), and predicts the noise component \(\epsilon_\theta(x_t, t)\) contained in the image. Recall the forward diffusion formulation:

    \[ x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon \]

    Once the noise is estimated, we can invert this relation to recover an estimate of the clean image:

    \[ \hat{x}_0 = \frac{x_t - \sqrt{1-\bar{\alpha}_t}\,\epsilon_\theta(x_t,t)} {\sqrt{\bar{\alpha}_t}} \]

    This gives a one-step estimate of the original image directly from a noisy observation. Compared with Gaussian blur, the learned denoiser is able to restore more meaningful image structure, since it leverages a pretrained image prior instead of only performing local smoothing.

Iterative Denoising 1.4

  1. Although one-step denoising can recover clean images from moderately noisy inputs, directly predicting \(x_0\) from highly corrupted images becomes increasingly difficult as the noise level grows.

    Diffusion models solve this problem by gradually reversing the forward diffusion process. Instead of directly mapping:

    \[ x_t \rightarrow x_0 \]

    the model performs a sequence of smaller denoising transitions:

    \[ x_t\rightarrow x_{t'}\rightarrow x_{t''}\rightarrow ...\rightarrow x_0, \qquad t'<t \]

    At each reverse step, the UNet first predicts the noise component contained in the current noisy image:

    \[ \epsilon_\theta(x_t,t) \]

    Based on the predicted noise, we can estimate the clean image:

    \[ \hat{x}_0= \frac{x_t-\sqrt{1-\bar{\alpha}_t} \epsilon_\theta(x_t,t)} {\sqrt{\bar{\alpha}_t}} \]

    A natural question is: after obtaining \(\hat{x}_0\), why not simply add a smaller amount of noise back to generate \(x_{t'}\)?

    For example, one possible approach would be:

    \[ x_{t'} = \sqrt{\bar{\alpha}_{t'}}\hat{x}_0 + \sqrt{1-\bar{\alpha}_{t'}}z \]

    However, this ignores the information contained in the current noisy image \(x_t\). The reverse process should not randomly generate a new noisy image from \(\hat{x}_0\); instead, it should follow a consistent trajectory from the current state \(x_t\) toward the clean image.

    Therefore, diffusion models use the posterior transition:

    \[ q(x_{t'}|x_t,x_0) \]

    which combines information from both the current noisy image and the estimated clean image. The resulting transition is:

    \[ x_{t'}= \frac{\sqrt{\bar{\alpha}_{t'}}\beta_t} {1-\bar{\alpha}_t}\hat{x}_0 + \frac{\sqrt{\alpha_t}(1-\bar{\alpha}_{t'})} {1-\bar{\alpha}_t}x_t + v_\sigma \]

    This equation can be interpreted as a weighted combination of:

    1. the predicted clean image \(\hat{x}_0\), which provides the denoising direction;
    2. the current noisy state \(x_t\), which preserves trajectory consistency;
    3. a small random noise term \(v_\sigma\), which maintains stochastic sampling.

    Therefore, each reverse step only solves a small denoising problem instead of reconstructing all missing information from a highly noisy image at once.

Classifier-Free Guidance 1.6

  1. Although diffusion models can generate images from pure noise, the samples in the previous section are completely random and lack strong control over the generated content.

    To make diffusion models generate images following a desired condition (such as a text prompt), we can introduce Classifier-Free Guidance (CFG).

    In conditional diffusion models, the UNet predicts the noise component conditioned on an additional input \(c\):

    \[ \epsilon_\theta(x_t,t,c) \]

    where \(c\) represents the condition, such as the text embedding of a prompt:

    \[ c = \text{"a high quality photo"} \]

    However, directly using only the conditional prediction does not always produce the best results. The model needs to balance two objectives:

    • maintaining the general image prior learned from the dataset;
    • following the specific condition provided by the prompt.

    CFG achieves this by running the UNet twice at each denoising step:

    First, we obtain an unconditional noise prediction by providing an empty prompt:

    \[ \epsilon_u = \epsilon_\theta(x_t,t,\emptyset) \]

    This represents the model's natural denoising direction without any external guidance.

    Then, we obtain a conditional noise prediction using the actual prompt:

    \[ \epsilon_c = \epsilon_\theta(x_t,t,c) \]

    The difference between these two predictions:

    \[ \epsilon_c-\epsilon_u \]

    represents the additional denoising direction introduced by the condition. CFG amplifies this direction using a guidance scale \(\gamma\):

    \[ \boxed{ \epsilon = \epsilon_u + \gamma(\epsilon_c-\epsilon_u) } \]

    When \(\gamma=0\), the model performs unconditional generation. When \(\gamma=1\), it becomes standard conditional diffusion. Increasing \(\gamma\) strengthens the influence of the prompt and makes the generated image better align with the condition.

    Intuitively, CFG does not directly create a new image. Instead, during every reverse diffusion step, it modifies the predicted noise direction so that the sampling trajectory is pushed closer to the desired condition.

    \[ x_t \rightarrow \epsilon \rightarrow x_{t'} \rightarrow ... \rightarrow x_0 \]

    In my implementation, the iterative_denoise_cfg function follows the same reverse diffusion process as before, but replaces the original noise prediction with the CFG-guided noise estimate.

SDEdit 1.7.0

  1. In previous sections, we saw that diffusion models can gradually transform noisy images back into realistic images through the reverse diffusion process. This can be interpreted as projecting an image back onto the natural image manifold learned from the training data.

    This property enables image-to-image translation. Instead of starting from pure noise, we start from an existing image, add a controlled amount of noise, and then run the reverse diffusion process:

    \[ x_0 \rightarrow x_t \rightarrow x'_0 \]

    The added noise determines how much freedom the diffusion model has during reconstruction. With a small noise level, most original structures are preserved and the output remains close to the input image. With a larger noise level, more information is destroyed, allowing the model to generate new details based on its learned image prior.

    \[ \text{low noise} \rightarrow \text{preserve content} \] \[ \text{high noise} \rightarrow \text{stronger editing} \]

SDEdit with Binary Mask 1.7.2

  1. In the previous sections, SDEdit modified the entire image. However, what if we only want to edit a specific region while preserving everything else? This motivates image inpainting, where a binary mask determines which pixels the diffusion model is allowed to modify.

    Let \(m\) denote the binary mask, where \(m=1\) indicates the region to be generated and \(m=0\) indicates the region to be preserved.

    A straightforward idea would be to replace the unmasked region with the original image after every denoising step. However, the reverse diffusion process operates at different noise levels. Directly inserting clean pixels into a noisy intermediate image would create a mismatch between the two regions.

    Instead, at each timestep \(t\), we first add the corresponding amount of noise to the original image:

    \[ x_t^{\mathrm{orig}} = \sqrt{\bar{\alpha}_t}x_{\mathrm{orig}} + \sqrt{1-\bar{\alpha}_t}\epsilon \]

    We then combine the current generated image with the noisy original image using the mask:

    \[ \boxed{ x_t \leftarrow m\odot x_t + (1-m)\odot x_t^{\mathrm{orig}} } \]

    Here, \(\odot\) denotes element-wise multiplication. The masked region retains the newly generated content, while the unmasked region is replaced with the corresponding noisy original pixels.

    By repeating this operation throughout iterative denoising, we allow the model to generate new content inside the mask while preserving the original image outside it. This is a simplified, RePaint-inspired inpainting approach.

  1. So far, we have used SDEdit to modify existing images with a general prompt such as "a high quality photo". However, this provides little control over what the edited image should contain.

    To introduce semantic control, we can combine SDEdit with Classifier-Free Guidance (CFG). SDEdit determines how much information from the original image is preserved, while CFG steers the reverse diffusion process toward a desired text prompt.

    \[ x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon \]

    \[ \hat{\epsilon} = \epsilon_u + \gamma(\epsilon_c-\epsilon_u) \]

Visual Anagram with CFG 1.8

  1. Beyond generating images from a single text prompt, we can also combine multiple CFG predictions to satisfy different visual conditions simultaneously. One interesting application is Visual Anagrams, where the same image reveals different subjects when rotated by 180 degrees.

    The key idea is to guide the diffusion process with two different prompts at every denoising step: one for the upright image and another for its upside-down version.

    First, given the current noisy image \(x_t\), I compute a CFG-guided noise prediction using the first prompt \(p_1\):

    \[ \epsilon_1 = \operatorname{CFG}(x_t,t,p_1) \]

    Next, I rotate the current image by 180 degrees and compute another CFG prediction using the second prompt \(p_2\):

    \[ \epsilon_2' = \operatorname{CFG} (\operatorname{flip}(x_t),t,p_2) \]

    Since the second prediction is computed in the rotated coordinate system, we must flip it back before combining the two predictions. Otherwise, their spatial positions would not align.

    \[ \epsilon_2 = \operatorname{flip}(\epsilon_2') \]

    Finally, I average the two aligned noise predictions to obtain a single guided estimate:

    \[ \boxed{ \hat{\epsilon} = \frac{\epsilon_1+\epsilon_2}{2} } \]

    This combined estimate replaces the usual CFG noise prediction in the reverse diffusion step. By repeating this operation throughout sampling, the model attempts to generate an image that satisfies both prompts under their respective orientations.

Hybrid Images with CFG 1.9

  1. Another way to combine multiple CFG predictions is through Hybrid Images, which can convey different visual meanings depending on the viewing distance.

    The underlying idea comes from frequency-based image processing. Low spatial frequencies describe broad shapes and overall image structure, while high spatial frequencies capture finer details, textures, and edges. When viewed from a distance, high-frequency details become less distinguishable, allowing low-frequency structures to dominate perception.

    Instead of combining two completed images, I apply this frequency decomposition directly to the CFG noise predictions at each denoising step. This allows two different prompts to influence the same diffusion sampling trajectory.

    First, I compute two CFG-guided noise predictions using different text prompts:

    \[ \epsilon_1 = \operatorname{CFG}(x_t,t,p_1) \] \[ \epsilon_2 = \operatorname{CFG}(x_t,t,p_2) \]

    I then apply a Gaussian low-pass filter to the first prediction to extract its low-frequency components:

    \[ \epsilon_{\mathrm{low}} = G_\sigma * \epsilon_1 \]

    Similarly, I extract the high-frequency components of the second prediction by subtracting its Gaussian-blurred version:

    \[ \epsilon_{\mathrm{high}} = \epsilon_2-G_\sigma * \epsilon_2 \]

    Here, \(G_\sigma\) denotes the Gaussian kernel, and \(*\) represents convolution.

    Finally, I combine these two frequency components to obtain the guided noise estimate:

    \[ \boxed{ \hat{\epsilon} = \epsilon_{\mathrm{low}} + \epsilon_{\mathrm{high}} } \]

    The combined prediction is then used in the regular reverse diffusion step. Repeating this operation encourages the generated image to incorporate the broad structures associated with the first prompt and the finer details associated with the second.

Architecture overview

How the denoising UNet is organized

Before training the denoiser, I used the unconditional UNet specified by the assignment: an encoder–decoder whose contracting and expanding paths are joined by channel-wise skip connections.

Learning objective

Given a noisy image \(z\), the network \(D_\theta\) predicts its clean target \(x\). Training minimizes the expected pixel-wise squared reconstruction error.

\[ L=\mathbb{E}_{z,x}\left\lVert D_\theta(z)-x\right\rVert^2 \]
01 · Stem

\(1\times28\times28 \rightarrow D\times28\times28\)

A ConvBlock lifts the grayscale input into \(D\) feature channels while preserving its spatial resolution.

02 · Encoder

\(28\rightarrow14\rightarrow7\)

Two DownBlocks progressively reduce the spatial size and expand the channel capacity from \(D\) to \(2D\), building increasingly global features.

03 · Bottleneck

\(2D\times7\times7 \leftrightarrow 2D\times1\times1\)

Flatten compresses the lowest-resolution feature map to a global representation; Unflatten expands it back to the \(7\times7\) decoding stage.

04 · Decoder + skips

\(7\rightarrow14\rightarrow28\)

UpBlocks restore resolution. Encoder features are concatenated at matching scales before a final ConvBlock and \(3\times3\) convolution return one channel.

Building blocks and tensor operations

The architecture is assembled from a small set of resolution-preserving, downsampling, upsampling, bottleneck, and feature-fusion operations.

Conv / ConvBlock
A \(3\times3\), stride-1, padding-1 convolution followed by BatchNorm and GELU; ConvBlock applies two such Conv operations without changing resolution.
DownConv / DownBlock
A \(3\times3\), stride-2, padding-1 convolution halves height and width; DownBlock follows it with a ConvBlock.
UpConv / UpBlock
A \(4\times4\), stride-2, padding-1 transposed convolution doubles height and width; UpBlock then refines the features with a ConvBlock.
Flatten
Average pooling over the \(7\times7\) feature map, followed by GELU, produces a \(1\times1\) global representation.
Unflatten
A \(7\times7\) transposed convolution, BatchNorm, and GELU expand the \(1\times1\) bottleneck back to \(7\times7\).
Concat
Features with the same spatial dimensions are concatenated channel-wise with torch.cat(), carrying encoder detail into the decoder.

Design intuition. The downsampling path captures broad context, the bottleneck summarizes the image globally, and the skip connections preserve the fine spatial information that the decoder needs to reconstruct a clean digit.

    We can see that no matter what random noise we feed in, the model tends to output something that looks like a blurry “9”. This is basically the model collapsing to an “average digit” over the training set. The reason is that with an MSE loss, the best prediction for a given input is the conditional mean E[x｜z]. But here z is pure Gaussian noise and it has almost no relationship with the target clean image x, so E[x｜z] is roughly just E[x], i.e., the dataset mean (similar to a centroid in clustering). Since the input doesn’t provide any useful hint about which digit it should reconstruct, predicting this average-looking digit is an easy way to reduce the overall squared error.
